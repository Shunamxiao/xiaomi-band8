# v0.1.0 — First public release

自建小米手环 8（NFC）BLE 客户端首个公开版本。

## 包含内容

- PC 端 Python 客户端（Bleak）：扫描、密钥库、认证、电量、通知、查找
- Android App（Kotlin）：协议栈、前台服务、通知转发、设备配置界面
- 本地绑定协议实现（P-256 ECDH + HKDF，实验性）
- FastAPI 服务端 + Ant Design 风格 Web 控制台
- MCP 工具与桌搭守护进程
- 协议文档、链路梳理、能力清单、UI 设计说明

## 已验证

- 认证与 AES-CCM 加密通道
- 电量读取
- 通知推送（含 key 字段）
- 查找手环
- 免打扰、手机静音
- 床头钟 / 桌搭
- PC 直连（不依赖手机）

## 已知限制

- 本地绑定需要未绑定/已解绑的手环，字段顺序待真机验证
- 已绑定手环无法被第三方直接接管
- 自定义表盘仍在研究中
- 通知震动为全局开关；固件不支持单条静默通知

## 安全

- 仓库不包含任何真实设备密钥、MAC 或内网地址
- 密钥库 band8/keystore.json 已被 .gitignore 排除
